# Git 分支快速切换设计

## 目标

在项目工作区提供一个紧凑的 Git 分支入口，快速查看并切换当前项目的本地分支。分支属于项目级状态，与选中的命令标签无关。

## 界面

- 在命令标签栏右侧显示分支按钮，例如 `⑂ main ▾`。项目编辑和删除已由左侧项目右键菜单提供，不在命令栏重复显示。
- 点击后打开锚定在按钮下方的小型列表，显示当前分支、搜索框、本地分支列表和刷新操作。
- 当前分支显示勾选状态；选择其他分支后更新按钮文字。
- 若项目目录不是 Git 仓库，在列表中显示明确说明；分支加载失败时显示错误和重试入口。
- 当项目有启动中、运行中或停止中的命令时，禁用分支切换并提示先停止命令。不会自动停止服务。

## 操作与边界

- 使用 Rust 命令层执行 Git CLI；所有参数以独立参数传入，不拼接 shell 命令。
- 列表仅包含本地分支；V1 不创建/删除分支，也不显示远程分支。
- 切换使用 `git switch`。不强制覆盖工作区；Git 因未提交改动等原因拒绝时，将错误反馈给用户并保留原分支。
- 切换前由后端再次确认该项目没有活动会话，避免前端状态过期造成运行中切换。
- 成功后重新读取当前分支和分支列表；切换失败时保持原显示并展示错误。
- 项目切换时重新加载该项目的分支状态；弹层每次打开时刷新。

## 实现边界

- Rust 负责仓库检查、读取本地分支、当前分支读取和受保护的切换操作。
- Tauri API 层提供项目 ID 参数化的分支接口；项目路径从已保存的项目配置中解析，不接受前端任意路径。
- Vue 在项目工作区持有分支弹层开合、搜索草稿、加载/错误和已读取分支状态，并通过 API 调用 Rust。
- 分支选择器作为独立 UI 单元嵌入现有命令标签栏，不改变命令管理和会话生命周期。

## 验收标准

- Git 项目能显示当前分支及本地分支列表，搜索和刷新可用。
- 选择有效分支后工作区完成切换，按钮显示新分支。
- 非 Git 目录、Git 命令不可用或切换失败时，界面给出可读反馈。
- 项目有活动命令时，前端和后端都阻止分支切换，且不会自动终止命令。
- 未提交改动不会被强制覆盖。
